# Reporting Guide

## Select the reporting scope

Choose the authorized company, branch and payroll period. Reports use the employees and saved payroll rows visible for that scope; the supplied reference files are examples of report appearance and requested report types, not a fixed employee count or universal 12-column restriction.

## Generate a report

1. Select a report type and the intended finalized payroll run where required.
2. Review the preview, selected employee count and validation messages.
3. Correct missing required source fields through the normal authorized HR/payroll workflow.
4. Export only after the preview matches the intended company, branch and period.
5. Open the downloaded file and confirm its period and totals before external use.

The Leave Days report omits the B/F column. Bank, cash and mobile-money reports are filtered by the employee's registered payment method. The Master Payroll report is the consolidated payroll snapshot; component reports should reconcile to it, allowing only explicitly configured split payments.

## Compliance exports and limitations

NAPSA and NHIMA contribution schedules are generated from approved payroll data and are internal schedules unless and until an official regulator format is verified. PAYE workbook headings and sample styling are implemented from the supplied example. Do not assume an exported file has been accepted or submitted to a regulator. No statutory filing is sent by the application.

Report files can contain employee statutory identifiers, salaries, deductions or bank details. Save them only to approved private storage and share them only with authorized recipients.
