# Golden Baobab HR

Golden Baobab HR is a premium multi-company HR and payroll management frontend for Zambian businesses. This workspace currently contains a frontend-only design preview populated with synthetic demo data.

## Run locally

```sh
npm install
npm run dev
```

## Verify

```sh
npm run typecheck
npm run build
```

The preview includes a responsive dashboard, company switcher, light and dark themes, and navigation screens for organizations, companies, branches, employees, attendance, leave management, payroll, statutory deductions, reports, users and permissions, audit logs, and settings.

All people and business figures shown in the preview are synthetic. The frontend does not configure authentication, a database, or external services.
